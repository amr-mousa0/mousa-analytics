# Data Model: Decap CMS Collections & Schemas

This document defines the schema definitions for the Content Collections managed by Decap CMS.

---

## 1. Services Collection (`services`)

- **Path**: `src/content/services/`
- **Languages**: English (`en/`) and Arabic (`ar/`)
- **Type**: Content Collection (Markdown)

### Fields

| Field Name | Type | Widget | Required | Description |
|------------|------|--------|----------|-------------|
| `title` | String | text | Yes | The user-facing service name. |
| `slug` | String | slug | Yes | URL Slug (autogenerated from title, readonly after creation). |
| `description` | String | text | Yes | Short introductory text outlining the service value. |
| `icon` | String | text | Yes | Lucide or FontAwesome icon identifier (e.g. `chart-line`). |
| `features` | List (Strings) | list | No | Bullet list of specific service deliverables. |
| `priority` | Integer | number | Yes | Sorting weight (ascending). |
| `category` | String | select | Yes | Reusable category for filtering (referenced from taxonomy). |
| `tags` | List (Strings) | list | No | Reusable tags for filtering. |
| `translationKey` | String | string | Yes | Unique ID connecting the Arabic and English versions of this service. |
| `draft` | Boolean | boolean | Yes | Hide from build output if true (default `false`). |
| `featured` | Boolean | boolean | Yes | Highlight on homepage if true (default `false`). |
| `publishedDate` | Date | datetime | Yes | Publication date. |
| `seo` | Object | object | Yes | SEO specific tags (see SEO block). |

## 3. SEO Fields Block (`seo`)

Structured field container added to both Services and Projects:

| Field Name | Type | Widget | Required | Description |
|------------|------|--------|----------|-------------|
| `metaTitle` | String | string | Yes | Title element override for search results. |
| `metaDescription`| String | string | Yes | Meta description tags (max 160 characters). |
| `ogImage` | Image | image | No | OpenGraph custom social share image. |
| `canonicalUrl` | String | string | No | Custom canonical link override. |
| `structuredData` | Object | object | No | Custom schema.org JSON-LD field overrides. |
| `noindex` | Boolean | boolean | No | Exclude from search index if true (adds `noindex` meta tag). |

## 4. Media & Asset Folder

To enable Astro's native `<Image />` component for optimization and WebP conversion:

- **Media Folder (CMS writes to)**: `src/assets/images/uploads`
- **Public Folder (Relative inside Markdown)**: `../../../assets/images/uploads`
- **Upload Limit**: Maximum 5MB per image.
- **Formats allowed**: `.webp`, `.png`, `.jpg`, `.jpeg`.
- **Processing strategy**: Astro automatically converts cover and gallery images to WebP format at build time via the Sharp integration. Filenames are automatically normalized to lowercase alphanumeric characters and hyphens during CMS upload.

---

## 5. Backup & Migration Integrity

To safeguard current hardcoded page content:
- **Temporary Backup Folder**: `src/pages/[lang]/projects/.backup/`
- **Recovery Action**: In case of dynamic layout compile failure, files are restored to `src/pages/[lang]/projects/` and content collection schemas are bypassed until build returns to a healthy state.
