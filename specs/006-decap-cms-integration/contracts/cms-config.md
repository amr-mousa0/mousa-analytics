# Contract: Decap CMS Configuration Schema

This contract defines the structure of `public/admin/config.yml` used to load the CMS workspace.

---

## 1. Global Settings

- `backend`: Must utilize `git-gateway` in production.
- `publish_mode`: Set to `editorial_workflow` in production to support drafts, previews, and pull requests.
- `local_backend`: Set to `true` to enable local proxy development.
- `media_folder`: `src/assets/images/uploads` (for Astro compilation).
- `public_folder`: `../../../assets/images/uploads` (relative route from collections).

---

## 2. DRY Structures (YAML Anchors & Aliases)

To eliminate configuration duplication, we define reusable field blocks using YAML anchors:

### Reusable SEO Fields Anchor (`&seo_fields`)
```yaml
seo_fields: &seo_fields
  name: seo
  label: SEO & Metadata
  widget: object
  fields:
    - { label: "Meta Title", name: "metaTitle", widget: "string" }
    - { label: "Meta Description", name: "metaDescription", widget: "string" }
    - { label: "OG Image", name: "ogImage", widget: "image", required: false }
    - { label: "Canonical URL", name: "canonicalUrl", widget: "string", required: false }
    - { label: "No Index", name: "noindex", widget: "boolean", default: false }
```

### Reusable Common Content States Anchor (`&content_states`)
```yaml
content_states: &content_states
  - { label: "Draft", name: "draft", widget: "boolean", default: false }
  - { label: "Featured", name: "featured", widget: "boolean", default: false }
  - { label: "Publish Date", name: "publishedDate", widget: "datetime" }
  - { label: "Translation Key", name: "translationKey", widget: "string" }
```

## 3. Collections Setup (Using Aliases)

### Services Collection Schema (`services_en` / `services_ar`)
- **Target Folder**: `src/content/services/en` / `src/content/services/ar`
- **Identifier**: `slug` (using `{{slug}}`)
- **Enforced Fields**:
  - `title` (string)
  - `slug` (widget: `slug`, readonly: true, hint: "Autogenerated from title. Cannot be modified after creation to prevent route breaks.")
  - `description` (text)
  - `icon` (string)
  - `priority` (number)
  - `features` (list of strings, optional)
  - `category` (select widget, options: ["Data Analytics", "Digital Marketing", "Systems Automation", "Web Development"])
  - `tags` (list of strings, optional)
  - `<<`: *content_states  # Injects draft, featured, publishedDate, translationKey
  - `*seo_fields`          # Injects full SEO metadata block

### Projects Collection Schema (`projects_en` / `projects_ar`)
- **Target Folder**: `src/content/projects/en` / `src/content/projects/ar`
- **Identifier**: `slug` (using `{{slug}}`)
- **Enforced Fields**:
  - `title` (string)
  - `slug` (widget: `slug`, readonly: true, hint: "Autogenerated from title. Cannot be modified after creation to prevent route breaks.")
  - `projectBadge` (string)
  - `problemTitle` (string)
  - `problemText` (text)
  - `solutionTitle` (string)
  - `solutionText` (text)
  - `impactTitle` (string)
  - `impactText` (text)
  - `galleryTab` (string)
  - `dashboardTab` (string)
  - `dashboardPrompt` (string)
  - `dashboardBtn` (string)
  - `inquireTitle` (string)
  - `inquireDesc` (string)
  - `inquireBtn` (string)
  - `galleryImages` (list of images)
  - `coverImage` (image)
  - `githubUrl` (string, optional)
  - `whatsappStartProjectMsg` (string)
  - `whatsappOpenDashboardMsg` (string)
  - `priority` (number)
  - `category` (select widget, options: ["Data Analytics", "Digital Marketing", "Systems Automation", "Web Development"])
  - `tags` (list of strings, optional)
  - `<<`: *content_states  # Injects draft, featured, publishedDate, translationKey
  - `*seo_fields`          # Injects full SEO metadata block
